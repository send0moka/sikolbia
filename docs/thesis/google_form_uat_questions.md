TUJUAN UAT:
Kuesioner ini bertujuan untuk mengevaluasi tingkat penerimaan dan kelayakan sistem SIKOLBIA dalam mendukung prediksi konsumsi kalori per kapita nasional untuk perencanaan ketahanan pangan Indonesia.

TENTANG SISTEM:
SIKOLBIA adalah sistem berbasis web yang mengintegrasikan model machine learning LSTM untuk memprediksi konsumsi kalori dari data historis Neraca Bahan Makanan (NBM). Sistem ini dikembangkan untuk mendukung pengambilan keputusan terkait kebijakan ketahanan pangan nasional.

## CATATAN UNTUK PEMBUAT FORM:

### Setup Google Form:

1. **Judul Form:** "UAT Sistem SIKOLBIA - Kuesioner User Acceptance Testing"

2. **Deskripsi:**
   ```
   Kuesioner ini bertujuan untuk mengevaluasi tingkat penerimaan pengguna terhadap 
   Sistem Informasi Konsumsi Pangan Nasional Berbasis Long Short-Term Memory (SIKOLBIA).
   
   Waktu pengisian: ±15 menit
   Responden: Pengguna sistem dari Badan Pangan Nasional, Kementerian Pertanian, 
   Bappenas, dan Akademisi
   ```

3. **Pengaturan:**
   - ✓ Batasi ke 1 respons
   - ✓ Wajib login Google
   - ✓ Kumpulkan alamat email
   - ✓ Semua pertanyaan wajib diisi (kecuali Bagian E)

4. **Jenis Pertanyaan di Google Form:**
   - Informasi Responden → "Jawaban Singkat" atau "Pilihan Ganda"
   - Pertanyaan A1-D6 → "Pilihan Ganda" atau "Skala Linear" (1-5)
   - Bagian E → "Paragraf" (tidak wajib)

5. **Tips Menggunakan Skala Linear:**
   - Skala: 1 s.d. 5
   - Label 1: Sangat Tidak Setuju (STS)
   - Label 5: Sangat Setuju (SS)

6. **Export Data:**
   - Setelah pengisian selesai, export ke Google Sheets
   - Hitung skor menggunakan formula yang ada di laporan
   - Masukkan hasil ke Tabel 24-27 di laporan
